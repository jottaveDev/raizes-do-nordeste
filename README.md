# Raízes do Nordeste

Protótipo acadêmico de uma plataforma de pedidos para uma rede fictícia de comida nordestina. A aplicação reúne cardápio por unidade, carrinho, pedidos, promoções, fidelidade e recursos de privacidade. Os dados são simulados; nenhum pagamento real é processado.

## Executar localmente

```bash
npm install
npm run dev
```

## Conclusão

O desenvolvimento mostrou como organizar uma aplicação React em páginas, componentes, contextos e serviços, além de integrar navegação, estado compartilhado e persistência local. Entre os principais desafios estiveram manter coerentes os fluxos de pedido e autenticação e apresentar, de forma clara, recursos que no protótipo dependem apenas de dados locais.

Como evolução, os principais pontos de atenção são substituir os dados simulados por uma API com autenticação segura, integrar um provedor real de pagamento, validar acessibilidade e testes, e revisar os fluxos de privacidade e tratamento de dados antes de qualquer uso com clientes.
